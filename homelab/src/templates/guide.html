How to Install LG TV Firmware via USB Drive

Step-by-step instructions for updating your LG OLED TV (CX, B4, and other webOS models) using a USB flash drive.

Official LG Guide Return to Dashboard

✓ Prerequisites

USB Flash Drive

At least 4 GB capacity, formatted with FAT32 or NTFS. Avoid exFAT/APFS.

Firmware Archive

Downloaded .zip package from this monitor's dashboard or official LG support.

Stable Power

Do not power off TV or unplug USB while update is running (takes approx. 5-15 mins).

1

Download Firmware & Format USB Flash Drive

Download the latest firmware archive (e.g. Software_File(Version_xx.xx.xx).zip) for your TV model using the Download Firmware button on the dashboard.

Plug your USB drive into your PC or Mac. Make sure it is formatted as FAT32 or NTFS.

2

Create the LG_DTV Folder on the USB Root

In the root directory of your USB flash drive (top level, NOT inside another folder), create a new folder named exactly:

Folder Name: LG_DTV
Important: The folder name must be uppercase LG_DTV. LG webOS will not detect the update if it's named lowercase or misspelled.
3

Extract the .epk File into LG_DTV

Unzip / extract the downloaded zip file on your computer. Inside you will find a file ending with the .epk extension (e.g. starfish-dvb-secured-m24-33.31.75...epk).

Copy that .epk file directly into the LG_DTV folder on the USB drive. Do NOT rename the file.

// Correct USB Drive Structure:
USB Flash Drive /
└── LG_DTV /
└── starfish-...-33.31.75.epk (Extracted firmware file)
4

Insert USB Drive into LG TV

Safely eject the USB drive from your computer and plug it into any available USB port on your LG TV (located on the side or rear connectivity panel).

5

Acknowledge Prompts & Start Installation

• If a "USB CONNECTED" media prompt appears asking to view files or photos, select Stay (do not open media player).
• Within a few seconds, the TV will automatically recognize the firmware file and display a "Software Update" dialogue stating that a newer version was found.
• Select Install or Yes to begin the installation.
6

Monitor Progress & Automatic Reboot

The TV will copy the package and install the firmware. To view the live progress percentage bar:

On LG OLED CX (webOS 5.0) Settings ⚙️ → All Settings → General → About This TV
On LG OLED B4 (webOS 24) Settings ⚙️ → All Settings → Support → Software Update
WARNING: DO NOT turn off the TV, disconnect the power cord, or pull out the USB flash drive until the update completes and the TV restarts automatically.

When the progress reaches 100%, the TV will automatically restart within 5 seconds. After rebooting, a notification will state: "Software update is complete."

Troubleshooting FAQ

The TV does not detect the firmware on the USB drive

1. Folder Name: Verify the folder at the root of the USB drive is named exactly LG_DTV (all caps with underscore).

2. File Unzipped: Ensure you placed the unzipped .epk file inside LG_DTV, NOT the .zip archive.

3. Filesystem: LG TVs cannot read exFAT, APFS, or ext4. Reformat the USB drive to FAT32 or NTFS on a computer.

4. USB Port: Try plugging into another USB port on the TV, or avoid using unpowered USB extension cables.

Can I downgrade to an older firmware version?

Standard retail webOS does not permit downgrading to an older software version via USB. The TV will only prompt to install if the version on the USB key is strictly newer than the currently installed version.

How do I check my TV's exact model number?

Press the Settings (gear) button on your Magic Remote → All Settings → General (or Support) → About this TV → TV Information. The full product model string (e.g. OLED77B4PUA.AUS) is listed there.
